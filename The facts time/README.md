The Facts Time is a fully featured, single-page news web application built using HTML, CSS, and modern JavaScript that delivers real-time, category-based news with a secure authentication system. The application integrates the GNews API to fetch live Indian news across Business, Politics, Environment, Crime, Movies, and Sports, with robust retry logic and graceful error handling for network failures and invalid API keys. User authentication and profile management are implemented using Supabase, supporting email/password login, Google OAuth sign-in, secure password reset via email, profile editing, and profile image uploads through Supabase Storage. The interface follows a clean newspaper-style design with responsive layouts, modal-based login and registration, password visibility toggles, custom message dialogs, auto-login prompts for unauthenticated users, and session-aware UI updates. Advanced features include exponential backoff for API requests, recovery-mode password reset handling via URL tokens, real-time profile UI synchronization, and strong client-side validation, making this project a practical example of modern frontend development, third-party API integration, and secure authentication workflows.
